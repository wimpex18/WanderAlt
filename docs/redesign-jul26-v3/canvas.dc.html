3aThe system — one glass recipe, one unit, the single-line law
Dusk Glass · v4
The page is a place. Controls float over it on glass.
Three layers, never more: the scene (photo, map, or dusk gradient) · glass (every panel and control, one recipe) · signal (one lime action per screen). If an element can't say which layer it is, it doesn't ship.

The single-line law
· every control row: one line, fixed 48, flex + center, no wrap
· chip sets that overflow become a snap-scroll rail, never a second ragged line
· every meta line: one line, ellipsis — titles alone may take two
· columns in a row share one width; grids are repeat(n,1fr), gap 8
Type gets louder
· display: Fraunces 600, tighter −0.5%, up a step everywhere
· quotes: Fraunces italic 26/40, lime rule — still the loudest voice
· mono tickers (12px, .1em) replace every fussy label row
· body floor 14px; nothing under 10.5px mono
fallback: @supports not (backdrop-filter) → glass panels go solid #131b1c (Night Edition surfaces) · prefers-reduced-transparency respected · scene layer never carries text without a scrim
· this is the radical move turn 2 stopped short of: the interface becomes three named layers, and "which layer" replaces "which style" as the only design decision
· the Bootstrap review translated: one flex recipe (display:flex;align-items:center;height:48) is the d-flex/align-items-center equivalent, applied to literally every control row — no exceptions to audit
· brand survives intact: petrol + lime, Fraunces/Inter/Geist Mono — no new hues, no new faces
